# Study-Ai

A React + Vite study app with dashboard, flashcards, MCQ, mind map, notes, and upload pages.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open the app in your browser:
   ```
   http://localhost:5173/
   ```

## Build for production

```bash
npm run build
```

The static production files will be generated in the `dist/` directory.

## GitHub deployment

1. Create a GitHub repository.
2. Add the remote:
   ```bash
   git remote add origin https://github.com/janaktech05-max/Study-Ai.git
   ```
3. Push the main branch:
   ```bash
   git branch -M main
   git push -u origin main
   ```

## Notes

- This project uses Vite, React, TypeScript, Tailwind, and Zustand.
- If `npm` is blocked in PowerShell, run commands in Command Prompt or use `cmd /c`.
